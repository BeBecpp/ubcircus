# Content model

All ids are UUIDs. Timestamps are `timestamptz` stored in UTC; editorial display uses `Asia/Ulaanbaatar` (no DST). Locales: `mn` (default), `en`, `tr`. A missing translation falls back to Mongolian, then the first available locale. Translated free text lives in `*_translations` rows (one per locale, unique per parent); short translated labels (category labels, venue fields, media alt/caption, navigation labels) are JSON maps `{mn, en, tr}`.

## Tables (public schema)

| Table | Purpose | Notes |
| --- | --- | --- |
| `profiles` | staff identity + role | `id` = `auth.users.id`; `role` admin/editor; `active` |
| `event_categories`, `article_categories` | taxonomies | slug unique, JSON labels, order |
| `venues` | visitor information | localized JSON fields, `map_url`, `verified` flag surfaces an "unverified" notice publicly |
| `media_assets` | Supabase Storage objects | url, object_key, mime, size, dimensions, alt/caption JSON, credit, photographer, focal point, category, tags |
| `events` | one artistic production | slug, status, category, venue, duration, poster, hero, video, credits JSON, `sample`, `published_at` |
| `event_translations` | per-locale text | title, subtitle, excerpt, sanitized description, audience, SEO |
| `event_sessions` | **one scheduled performance** | `starts_at`, `ends_at`, status scheduled/sold_out/cancelled |
| `event_ticket_links` | booking link per session | label, `https://` url, price, currency, note |
| `event_gallery_items` | ordered event gallery | event ↔ media |
| `articles`, `article_translations` | stories | lead image, category, reading time, sanitized body |
| `videos`, `video_translations` | YouTube films | validated 11-char id, poster, featured, order |
| `galleries`, `gallery_translations`, `gallery_items` | archive collections | category (photography, performances, behind-the-scenes, posters, videos), ordered items with optional caption |
| `pages`, `page_translations` | institutional pages | about / visit / contact + any extra |
| `homepage_sections`, `homepage_section_items` | homepage curation | kind, enabled, order, settings JSON, ordered resource references |
| `navigation_items` | header/footer links | group, href, JSON labels, order |
| `site_settings` | key/value JSON | `site`, `locales`, `seo`, `contact` |
| `audit_entries` | who changed what | actor, action, resource, summary |
| `contact_messages` | public enquiries | ip hash, resolved flag |
| `rate_limit_buckets` | durable throttling | key, count, expiry |

Publishing states: `draft`, `scheduled`, `published`, `cancelled`, `archived`. Public endpoints return `published` rows only.

## Sessions, not strings

```
Event  "Odyssée"
  ├─ Session 2026-09-12 15:00  scheduled   ticket → https://…
  ├─ Session 2026-09-12 19:00  sold_out
  ├─ Session 2026-09-13 15:00  scheduled
  └─ Session 2026-09-13 19:00  cancelled
```

Query paths and the indexes that serve them:

| Query | Index |
| --- | --- |
| upcoming sessions across the programme | `event_sessions(starts_at)`, `event_sessions(status, starts_at)` |
| sessions of one production | `event_sessions(event_id)` |
| published events by date | `events(status, published_at)`, `events(status)` |
| event / article by slug | unique `events(slug)`, `articles(slug)` |
| translations by parent + locale | unique `(event_id, locale)` etc. |
| published stories newest first | `articles(status, published_at)` |
| homepage curation | `homepage_section_items(section_id)` |
| media by category | `media_assets(category)` |
| every foreign key | indexed |

## Security model (Postgres / Supabase)

Applied by Alembic migration `0001` on Postgres only (`app/db_security.py`):

- `public.is_staff()` / `public.is_admin()` — `security definer`, `search_path = ''`, read `profiles` for `auth.uid()`.
- Every table has RLS enabled. Content tables: one permissive `SELECT` policy (`published` rows for everyone, everything for staff) and separate staff-only `INSERT`/`UPDATE`/`DELETE` policies. Private tables (`profiles` beyond own row, `audit_entries`, `contact_messages`, `rate_limit_buckets`) have no anon/authenticated grants.
- `profiles.id` references `auth.users(id)` with cascade.
- Storage bucket `media` (public read, 25 MB, image MIME allow-list) with staff-only write policies on `storage.objects`.
- The API connects with the Postgres role from `DATABASE_URL` and is the only writer in practice.

## Sample content

`apps/api/app/seed/content.json` (generated by `scripts/build-content.mjs`) is idempotent and visibly fictional: six productions with 21 sessions, five stories, three videos without YouTube ids, four galleries, an unverified venue, three pages, nine homepage sections, navigation and settings.
